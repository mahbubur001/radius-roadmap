# LoopedIn — Product Research Docs

Research into **LoopedIn** (https://loopedin.io, app at https://app.loopedin.io), a SaaS tool that combines feedback collection, public roadmaps, changelogs and a knowledge base.

Researched: 2026-10-27.

> **Source note:** These docs are built from LoopedIn's public website, its public knowledge base (`app.loopedin.io/loopedin/kb`) and its API docs (`docs.loopedin.io`). The logged-in admin dashboard was **not** inspected (see [13-gaps-and-next-steps.md](13-gaps-and-next-steps.md)).
